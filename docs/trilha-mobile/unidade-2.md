# Unidade II – JavaScript & TypeScript para Mobile

**Tempo Estimado**: 1 semana

Antes de avançar para React Native, é fundamental dominar os conceitos de JavaScript moderno (ES6+) e TypeScript que serão usados ao longo de toda a trilha. Esta unidade garante que você tenha a base necessária para acompanhar as próximas unidades sem dificuldade.

!!! tip "Já domina JavaScript?"
    Se você já concluiu a **Trilha de Front-end (Unidade V – JavaScript)**, pode avançar para a Unidade III.
