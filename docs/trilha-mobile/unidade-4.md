## Desafios da Unidade IV

!!! example "[Exercício 1] App de Duas Telas"
    Construa um app simples com **duas telas** para praticar navegação básica com Stack Navigator:

    - Tela 1 (Home): lista de itens (ex: filmes, livros ou músicas favoritas)
    - Tela 2 (Detalhes): ao tocar em um item, navegar para uma tela com mais informações
    - Usar Stack Navigator para a transição entre telas
    - Passar o nome do item como parâmetro para a tela de detalhes

!!! example "[Exercício 2] Lista de Tarefas Simples"
    Construa um app de **Lista de Tarefas** básico utilizando `useState`:

    - Adicionar e remover tarefas
    - Marcar tarefas como concluídas (riscar o texto)
    - Usar `useState` para gerenciar a lista
    - Usar `FlatList` para renderizar as tarefas
