## Desafios da Unidade V

!!! example "[Exercício] Buscador de CEP"
    Construa um app simples que consome a **API ViaCEP** para buscar endereços a partir de um CEP digitado.

    **API:** [ViaCEP (gratuita, sem cadastro)](https://viacep.com.br/)

    - Campo de input para digitar o CEP
    - Botão de busca que faz a requisição `GET` para `https://viacep.com.br/ws/{cep}/json/`
    - Exibir os dados retornados: logradouro, bairro, cidade e estado
    - Exibir uma mensagem de erro caso o CEP seja inválido
