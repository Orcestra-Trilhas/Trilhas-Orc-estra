# Unidade III – React Native: Primeiros Passos

## Módulo 3.1: Primeiro App — "Hello Mobile World!"

Criar e rodar o primeiro aplicativo React Native com Expo para validar que tudo está funcionando.

**Passo a passo:**

```bash
npx create-expo-app@latest hello-mobile
cd hello-mobile
npx expo start
```

Escaneie o QR Code com o app **Expo Go** no celular ou abra no emulador.

## Desafios da Unidade III

!!! example "[Exercício 1] Hello Mobile World"
    Modifique o app criado no Módulo 3.1 para exibir:

    - Um título com seu nome
    - Uma imagem (pode ser uma foto sua ou um avatar)
    - Um botão que exibe um `Alert` com uma mensagem personalizada

!!! example "[Exercício 2] Meu Perfil"
    Construa uma tela de **Meu Perfil** utilizando os componentes e estilos aprendidos:

    - Usar `View`, `Text`, `Image` e `ScrollView`
    - Exibir foto, nome, bio curta e uma lista de hobbies
    - Estilizar com `StyleSheet` e Flexbox
    - Ao tocar na foto, exibir um `Alert` com uma mensagem
